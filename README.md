# conformance-paper

The paper repo that `oak conformance` runs against to test each oaktree-sapling release. Each run merges an upgrade into `main` and opens and closes its own pull requests, branches and tags, so leave the repo as it is: a change pushed by hand stays in place and can make the next run fail. See the [conformance docs](https://scholar.nexus/oaktree-sapling/design/conformance).
